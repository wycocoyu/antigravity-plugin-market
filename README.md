# Antigravity Plugins Market · 反重力插件市场

一个仿 Chrome Web Store 风格的 **Google Antigravity (AGY) 精选插件市场**，集中收录社区与开发者自研的好用插件，涵盖五大核心分类：

- **上下文 & 额度（Context & Quota）**：`antigravity-panel`、`antigravity-context-viewer`、`agy-context-dashboard`、`antigravity-metrics-capsule`
- **皮肤 & 美化（Themes & UI）**：川版暖纸补丁、毛玻璃动态主题、Pixel/P5/Matcha 主题包等
- **中文汉化（Localization）**：`Antigravity-Hans`、`antigravity_chinese`、`antigravity-desktop-zhcn` 等
- **ACP & 跨端桥接（ACP & Bridges）**：`antigravity-acp`、`pi-antigravity-acp-provider`、`antigravity-plugin-cc` 等
- **侧边栏 & 效率（Sidebar & Tools）**：`agy-project-sidebar`、`Antigravity-Manager`、`cockpit-tools`、`codegraph`

## 本地预览

```bash
python3 -m http.server 8765
# 打开 http://localhost:8765
```

## 投稿收录

欢迎通过 GitHub Issue 提交新的 Antigravity App 插件、皮肤、汉化补丁、ACP 适配或上下文工具，审核后合并进 `data/plugins.json` 即可自动展示。
